# Data Dictionary

| Field | Description |
| --- | --- |
| order_id | Order identifier |
| customer_id | Customer identifier |
| seller_id | Seller identifier |
| product_id | Product identifier |
| product_category_name | Product category |
| customer_state | Customer state |
| seller_state | Seller state |
| order_purchase_timestamp | Purchase timestamp |
| order_delivered_customer_date | Delivered timestamp |
| order_estimated_delivery_date | Estimated delivery timestamp |
| price | Item price |
| freight_value | Freight value |
| payment_value | Total order value used for analysis |
| review_score | Customer review score |
| delivery_days | Days between purchase and delivery |
| delivery_delay_days | Days delivered after estimated date |
| late_delivery_flag | Whether delivery missed estimated date |
| seller_tier | Seller performance tier |
| customer_order_number | Order sequence for customer |
| repeat_customer_flag | Whether customer has prior orders |
